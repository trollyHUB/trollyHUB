# 🏛️ GitHub Profile Maintenance Policy (`trollyHUB/trollyHUB`)

Этот регламент определяет правила управления версиями и коммитами для специального репозитория визитки профиля GitHub.

---

## 📌 Главное правило: «Единый коммит» (Single Commit Policy)

Для всех текущих правок, мелких доработок, обновления ссылок, навыков, баннера и стека:
1. **Всегда сохранять историю репозитория в состоянии ровно 1 коммита (`1 commit`)**.
2. Запрещено плодить второстепенные коммиты вида `fix: typo`, `update readme`, `edit banner`.
3. Любое обновление оформляется через дополнение существующего корневого коммита:
   ```bash
   git add .
   git commit --amend -m "feat: initial release of world-class GitHub Profile README for trollyHUB (Personal Exocortex, AI-Agentic, Multi-Platform Stack)"
   git push origin main --force
   ```

---

## 🚀 Исключение: Масштабные наработки и редизайн

* Если в будущем планируется **крупная переработка профиля** (развертывание сложных GitHub Actions, блога, динамических генераторов, мульти-страничной архитектуры):
  1. Этот файл (`AGENTS.md`) **удаляется из репозитория** (`git rm AGENTS.md`).
  2. Режим единого коммита отменяется.
  3. Репозиторий переводится на стандартный Semantic Commit Flow с сохранением полной истории версий.
